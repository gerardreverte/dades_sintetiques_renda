# Del percentil a la persona · From Percentile to Person

Pàgina web bilingüe (català / anglès) de l'article, amb les imatges i la descàrrega dels paràmetres Dagum i Pareto IV dels municipis catalans.

- `index.html` — pàgina completa (generada; no s'edita a mà)
- `img/`, `data/` — imatges i CSV
- `build/` — `build.py` + `template.html` per regenerar `index.html` a partir dels .docx

Publicació: GitHub Pages (Settings → Pages → branch `main`, carpeta `/ (root)`).
